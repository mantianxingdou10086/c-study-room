<KeyPoint>
  单独写成一句时，`i++;` 和 `++i;` 的效果完全一样，用哪个都行。
  一旦把自增嵌进别的表达式（比如 `a = i++;`），它就分出「先加还是后用」——
  这种写法是麻烦的起点，应该避免。
</KeyPoint>

## 赋值本身也是一个运算符

`x = 5` 这个式子是有值的，值就是 `5`。所以可以连着写：

```c
int a, b;
a = b = 5;      /* 从右往左：先 b = 5，再 a = b，两个都是 5 */
```

这只是「允许」，不推荐常用：一行里改两个变量，读的人要多想一步。
知道它合法，是为了看懂别人写的代码。

## 复合赋值：少写一遍变量名

| 简写 | 等价于 |
|---|---|
| `x += 5` | `x = x + 5` |
| `x -= 5` | `x = x - 5` |
| `x *= 5` | `x = x * 5` |
| `x /= 5` | `x = x / 5` |
| `x %= 5` | `x = x % 5` |

```c
total = total + price;    /* 两种写法完全等价 */
total += price;           /* 变量名越长，这一种越好读 */
```

注意右边是一个**完整的表达式**：`x *= 2 + 3` 等于 `x = x * (2 + 3)`，
也就是把 x 乘以 5，不是「先乘 2 再加 3」。

## 自增自减：前置与后置

```c
int i = 3;
int a = i++;    /* 后置：先把 3 交给 a，i 再变 4 —— a 是 3，i 是 4 */
int b = ++i;    /* 前置：i 先变 5，再把 5 交给 b —— b 是 5，i 是 5 */
```

判据很直接：`++` 写在变量**后面**，表达式的值是「加之前」的值；
写在变量**前面**，表达式的值是「加之后」的值。

单独成句时两者没有区别：

```c
i++;    /* i 加 1 */
++i;    /* i 也加 1，和上面那句完全一样 */
```

所以推荐的写法是：**单独成句时用 `i++`，永远不要把它塞进别的表达式**。

<TryIt title="i++ 与 ++i 的区别，一次看清">
{`#include <stdio.h>

int main(void)
{
    int i = 3;
    int a = i++;
    int b = ++i;

    printf("i=%d a=%d b=%d\\n", i, a, b);
    return 0;
}
`}
</TryIt>

输出是 `i=5 a=3 b=5`。注意 `a` 拿到的是 3——自增发生了，只是发生在赋值之后。
试着把 `int a = i++;` 改成 `int a = ++i;`，看三个值怎么变。

<Pitfall title="以为 i++ 表达式的值就是 i 的新值">
  `int a = i++;` 里，`a` 拿到的是**自增之前**的旧值。
  **判据**：看 `++` 在哪一边。在右边（后置）表达式的值是旧值，在左边（前置）才是新值。
</Pitfall>

<Pitfall title="把 += 打成了 =+">
  ```c
  x =+ 5;    /* 这是 x = (+5)：把 x 直接赋成 5，之前累加的结果全丢了 */
  x += 5;    /* 这才是 x = x + 5 */
  ```
  **判据**：等号后面紧跟 `+` 或 `-` 时，停下来确认自己写的是不是 `+=` / `-=`。
  这种错编译器不会报错，程序照样跑。
</Pitfall>

<Callout type="warn" title="同一行里对同一个变量自增两次">
  ```c
  i = i++ + i++;      /* ❌ 未定义行为 */
  ```
  这种写法在 C 标准里是**未定义行为**：不同编译器、不同优化级别可能给出不同结果。
  **判据**：同一行里同一个变量出现了两次 `++`，就一定是错的——拆成两行写。
</Callout>

## 这一节的结论
