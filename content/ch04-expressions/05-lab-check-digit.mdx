<KeyPoint>
  取余 `% 10` 拿到末位数字，整除 `/ 10` 把末位扔掉——这两步重复几遍，
  就能从右往左取出任意整数的每一位。这是很多算法题的基本功。
</KeyPoint>

## 任务

> 输入一个 6 位整数（例如 `314159`）。把它的每一位从右往左取出来：
> 最右边那位乘 1，往左依次乘 2、3、4、5、6，全部加起来得到加权和 `sum`；
> 校验位 = `(10 - sum % 10) % 10`。输出 `sum` 和校验位，中间用一个空格分开。

输入 `314159`，期望输出：

```
61 9
```

## 拆解

**第 1 步：取末位、扔掉末位**

```c
int n = 314159;
int d = n % 10;    /* d = 9 —— 末位拿到了 */
n = n / 10;        /* n = 31415 —— 末位没了 */
```

`% 10` 和 `/ 10` 是一对：一个把末位拿出来，一个把末位扔掉。
**顺序不能反**——先取，再扔。

**第 2 步：重复 6 次，每次乘上不同的权重**

从右往左手算一遍：

| 第几位（从右数） | 数字 | 权重 | 乘积 |
|---|---|---|---|
| 1 | 9 | 1 | 9 |
| 2 | 5 | 2 | 10 |
| 3 | 1 | 3 | 3 |
| 4 | 4 | 4 | 16 |
| 5 | 1 | 5 | 5 |
| 6 | 3 | 6 | 18 |

加起来：9 + 10 + 3 + 16 + 5 + 18 = 61。

**第 3 步：算校验位**

`sum % 10` 是 1，所以 `(10 - 1) % 10` 是 9。最外面那个 `% 10` 是为了处理
「加权和恰好是 10 的整数倍」的情况——那时 `10 - 0` 得到 10，再取余就变成 0。

## 完整程序

第 6 章才学循环，所以这里把 6 遍操作**手写展开**：

```c
#include <stdio.h>

int main(void)
{
    int n, d, sum, check;

    scanf("%d", &n);

    sum = 0;

    d = n % 10;  n = n / 10;  sum = sum + d * 1;    /* 权重 1 */
    d = n % 10;  n = n / 10;  sum = sum + d * 2;    /* 权重 2 */
    d = n % 10;  n = n / 10;  sum = sum + d * 3;    /* 权重 3 */
    d = n % 10;  n = n / 10;  sum = sum + d * 4;    /* 权重 4 */
    d = n % 10;  n = n / 10;  sum = sum + d * 5;    /* 权重 5 */
    d = n % 10;  n = n / 10;  sum = sum + d * 6;    /* 权重 6 */

    check = (10 - sum % 10) % 10;
    printf("%d %d\n", sum, check);
    return 0;
}
```

## 看见重复了吗

上面那 6 行的形状完全一样，只有乘的权重在变（1 到 6）。
你其实是在手写一个「做 6 次」的动作——第 6 章的循环会用 3 行把它写完：

```c
for (int i = 1; i <= 6; i++) {
    d = n % 10;  n = n / 10;  sum = sum + d * i;
}
```

现在先别用循环，把展开的版本写对——你才知道循环里面该放什么。

再试两个输入：`100000` 应该输出 `6 4`（前面五位都是 0，只有最左边的 1 参与了计算），

<Pitfall title="忘了每取完一位要把 n 缩小">
  如果只写 `d = n % 10;` 却漏掉 `n = n / 10;`，6 次拿到的都是同一个末位。
  **判据**：算出来的 `sum` 恰好等于末位数字乘 21（1+2+3+4+5+6 的和），就是漏了这一句。
</Pitfall>

<Pitfall title="先除后取，取错了位">
  ```c
  d = n / 10 % 10;    /* 这是十位，不是末位 */
  ```
  **判据**：想拿末位，`% 10` 必须是第一步；`n = n / 10` 永远写在取完之后。
</Pitfall>

<Pitfall title="忘了给累加变量赋初值">
  `int sum;` 之后直接写 `sum = sum + d * 1;`，加进去的是内存里的垃圾值。
  **判据**：累加变量在第一次被加之前，必须有一次 `sum = 0;`。
</Pitfall>
