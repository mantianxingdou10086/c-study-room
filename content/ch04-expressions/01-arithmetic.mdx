<KeyPoint>
  两个 `int` 相除，结果还是 `int`，小数部分被直接丢掉：`1 / 2` 是 `0`，不是 `0.5`。
  想让结果带小数，参与运算的数里至少要有一个是浮点数。
</KeyPoint>

## 五个运算符

| 运算符 | 含义 | 例子 | 结果 |
|---|---|---|---|
| `+` | 加 | `3 + 4` | `7` |
| `-` | 减 | `3 - 4` | `-1` |
| `*` | 乘 | `3 * 4` | `12` |
| `/` | 除 | `7 / 2` | `3`（注意） |
| `%` | 取余 | `7 % 2` | `1` |

C 里**没有乘方运算符**。想算 2 的 3 次方，不能写 `2 ** 3`，那在 C 里根本不是乘法。

## 整数除法：第一个「见鬼」的时刻

```c
printf("%d\n", 1 / 2);      /* 输出 0 —— 不是 0.5 */
printf("%d\n", 7 / 2);      /* 输出 3 —— 不是 3.5 */
printf("%d\n", -7 / 2);     /* 输出 -3 —— 向零截断，不是 -4 */
```

规则只有一句：**除号两边都是整数时，做整数除法，结果向零截断**。
不是四舍五入，也不是「先算出小数再想办法」。

| 写法 | 结果类型 | 值 |
|---|---|---|
| `1 / 2` | `int` | `0` |
| `1 / 2.0` | `double` | `0.5` |
| `7 / 2` | `int` | `3` |
| `7.0 / 2` | `double` | `3.5` |
| `7 % 2` | `int` | `1` |

只要有一个操作数是浮点，整条式子就按浮点算（第 4 节讲为什么）。

## 取余 % 的两个常见用途

- **判断能不能整除**：`n % 2 == 0` 说明 n 是偶数（第 5 章学了 `if` 就能用上）
- **取一个整数的末位数字**：`407 % 10` 是 `7`；想把末位去掉，用 `407 / 10` 得到 `40`
  （第 5 节的整节课都在用这一对操作）

`%` 只能用于整数，`7.0 % 2` 编译不过——这是它和 `/` 最不一样的地方。
负数的余数符号跟着**被除数**走：`-7 % 2` 是 `-1`，不是 `1`。

<TryIt title="整数除法与浮点除法，一次看清">
{`#include <stdio.h>

int main(void)
{
    printf("1 / 2   = %d\\n", 1 / 2);
    printf("1 / 2.0 = %.1f\\n", 1 / 2.0);
    printf("7 / 2   = %d\\n", 7 / 2);
    printf("7 %% 2   = %d\\n", 7 % 2);
    return 0;
}
`}
</TryIt>

跑完之后试着改一处：把 `1 / 2` 改成 `1 / 2.0`，看输出的类型提示怎么变；
再把 `7 % 2` 改成 `7.0 % 2`，亲手看一眼编译报错，比记住规则有用得多。

<Pitfall title="用 (a + b) / 2 算平均分">
  ```c
  int a = 3, b = 4;
  printf("%d\n", (a + b) / 2);   /* ❌ 输出 3，不是 3.5 */
  ```
  **判据**：先看除号两边。只要两边都是整数（变量声明成 `int`、字面量没有小数点），
  结果就一定是整数。修法是把其中一个数写成小数：`(a + b) / 2.0`。
</Pitfall>

<Pitfall title="把 % 当成百分比">
  C 里没有百分比运算，`50%` 不是「百分之五十」。
  另外在 `printf` 的格式串里要输出一个真正的百分号，必须写 `%%`。
</Pitfall>

<Callout type="info" title="为什么叫「向零截断」">
  `7 / 2` 是 `3`，`-7 / 2` 是 `-3`：都是把小数部分抹掉，让结果往 0 的方向靠。
  所以 `3.9` 会变成 `3` 而不是 `4`——它和四舍五入是两回事。
</Callout>

## 这一节的结论

`/` 和 `%` 是一对：`/` 回答「能装下几份」，`%` 回答「还剩多少」。
记住「两边都是整数就丢掉小数」这一条，你就能预判大多数「算错了」的结果。
