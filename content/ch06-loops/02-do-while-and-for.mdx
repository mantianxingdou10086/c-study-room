## for：把三件事挤进一行

上一节的 while 要把初始化、条件、推进分三处写。如果循环次数在写代码时就已经知道，
用 for 会更紧凑——三要素并排站在一对括号里：

```c
for (初始化; 条件; 推进) {
    循环体;
}
```

执行顺序是：**初始化只做一次** → 判断条件 → 执行循环体 → 执行推进 → 再判断……

```c
int i;
for (i = 1; i <= 5; i++) {
    printf("%d ", i);
}
```

这段和上一节那个 while 完全等价，输出都是 `1 2 3 4 5 `。
区别只在「读起来」：for 一眼就能看出从哪开始、到哪结束、每次走多少。

把两个写法并排摆着看，三件事只是换了位置：

| 三要素 | while 的写法 | for 的写法 |
|---|---|---|
| 初始化 | 写在循环前面单独一行 | 写在第一个分号前 |
| 循环条件 | `while (i <= 5)` | 写在两个分号中间 |
| 推进 | 写在循环体最后一行 | 写在第二个分号之后 |

C99 起还可以把声明也搬进 for 头部：`for (int i = 1; i <= 5; i++)`。
这样 i 出了循环就不存在了，能避免「这个变量怎么变了」的误伤（第 10 章讲作用域时会再遇到）。

推进那一格能写的东西不止 `i++`：倒着数用 `i--`，隔一个取一个用 `i += 2`，
翻倍用 `i = i * 2`。「每轮走多远」本身就是循环设计的一部分。

## 从 0 开始数

C 里最常见的计数范式是从 0 数到 n-1：

```c
for (i = 0; i < n; i++)   /* 正好跑 n 次 */
```

为什么不是从 1 数到 n？因为数组下标从 0 开始（第 8 章），
现在先记住这个习惯：**「跑 n 次」就写 `i < n`**。

## do-while：先做一遍，再判断

有些事必须至少做一次，比如「问用户要一个正数，他输错了就再问」：

```c
int n;
do {
    printf("请输入一个正数：");
    scanf("%d", &n);
} while (n <= 0);
```

do-while 先执行循环体，再检查条件：条件为真就回头再来一轮。
所以它和 while 的唯一区别是——**循环体至少执行一次**。
注意结尾那个分号，它是 do-while 语法的一部分。

## 三个循环怎么挑

| 场景 | 用哪个 | 例子 |
|---|---|---|
| 次数已知 | for | 打印 1 到 100 |
| 至少要执行一次 | do-while | 输入校验、反复显示菜单 |
| 其余（条件驱动） | while | 一直读到某个值为止 |

<Callout type="info" title="不要为了「统一」硬套一种">
  判据很简单：如果为了用 while 你得先算一下「到底会跑几次」，那这段代码本来就该用 for。
  选循环不是风格问题，是让读者少想一步。
</Callout>

<TryIt title="for 打印 1 到 5 的平方">
{`#include <stdio.h>

int main(void)
{
    int i;

    for (i = 1; i <= 5; i++) {
        printf("%d 的平方是 %d\\n", i, i * i);
    }
    return 0;
}
`}
</TryIt>

<Pitfall title="for 头部用逗号代替分号">
  ```c
  for (i = 0, i < 5, i++)    /* ❌ 编译不过 */
  ```
  for 头部的两个分隔符**必须**是分号，写成逗号编译器会直接报错。
  **判据**：数一数 for 后面那对括号里的分号，正好两个。
</Pitfall>

<Pitfall title="do-while 结尾漏了分号">
  ```c
  do {
      scanf("%d", &n);
  } while (n <= 0)    /* ❌ 少一个分号 */
  ```
  do-while 的结尾是 `} while (条件);`，分号不能省；而普通 while 语句结尾**不加**分号。
  **判据**：编译器提示「expected ';'」并且指着 while 那一行时，先查这里。
</Pitfall>

## 这一节的结论

for 适合「跑固定次数」，do-while 适合「至少跑一次」，while 适合「跑到条件不成立为止」。
三种循环的共同点你已经摸清了：都要有初始化、条件、推进。
