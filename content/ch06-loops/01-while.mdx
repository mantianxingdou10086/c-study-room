<KeyPoint>
  while 是「先判断、再执行」：条件为真才进循环体。它能不能停下来，
  取决于循环体里有没有东西在改变循环条件——变量一直不动，条件就永远成立。
</KeyPoint>

## 一个循环里的三件事

写循环的时候，脑子里要同时装三个角色，缺一个都不行：

| 角色 | 干什么 | 少了它会怎样 |
|---|---|---|
| 初始化 | 给循环变量一个起点 | 起点是垃圾值，结果不可预测 |
| 循环条件 | 决定还要不要再来一轮 | 不知道什么时候停 |
| 推进 | 让循环变量靠近出口 | 死循环 |

while 的写法，就是把这三件事摆成「判断 → 执行 → 再判断」：

```c
int i = 1;        /* 初始化：起点 */
while (i <= 5) {  /* 循环条件：还继不继续 */
    printf("%d ", i);
    i++;          /* 推进：让 i 靠近出口 */
}
```

i 依次是 1、2、3、4、5；执行完 5 之后 `i++` 把它变成 6，条件 `i <= 5` 不成立，循环结束。
整段输出 `1 2 3 4 5 `（每个数后面跟一个空格）。

## 把循环读一遍：跟踪变量的值

读循环最可靠的办法不是盯着代码猜，而是把每一轮的值写在纸上：

| 轮次 | 进循环体前 i 的值 | 条件 `i <= 5` | 这一轮输出 |
|---|---|---|---|
| 1 | 1 | 真 | `1 ` |
| 2 | 2 | 真 | `2 ` |
| 3 | 3 | 真 | `3 ` |
| 4 | 4 | 真 | `4 ` |
| 5 | 5 | 真 | `5 ` |
| 6 | 6 | 假 | 循环结束，什么都不打印 |

这张表只有 6 行，却一次回答了三个问题：循环跑了几次（5 次）、输出了什么（`1 2 3 4 5 `）、
为什么会停（i 变成 6，条件不成立）。以后遇到看不懂的循环，先列一张这样的表。

顺便说一个约定：循环变量习惯用 i、j、k 这种短名字。因为它只活在这几行里，
短名字反而让循环体更醒目；嵌套两层时用 i 和 j，不要让它们同名（这一章第 4 节会讲这个坑）。

## 条件一开始就是假

因为 while 是**先判断**，所以条件第一次就不成立时，循环体一次都不执行：

```c
int i = 10;
while (i < 5) {
    printf("这句话永远不会出现");
    i++;
}
```

这段代码不是死循环，只是白写了。反过来说也成立：想让循环体**至少执行一次**，while 做不到——
那要用 do-while（下一节）。

## 累加：循环最典型的用法

算 1 到 5 的和，思路是准备一个「累加器」，每轮往里加一个数：

<TryIt title="用 while 算 1 到 5 的和">
{`#include <stdio.h>

int main(void)
{
    int i = 1;
    int sum = 0;

    while (i <= 5) {
        sum = sum + i;
        i++;
    }
    printf("1 到 5 的和是 %d\\n", sum);
    return 0;
}
`}
</TryIt>

<Callout type="tip" title="累加器的固定套路">
  先写 `int sum = 0;`，再在循环体里写 `sum = sum + i;`。
  初值必须是 0——没初始化的变量是垃圾值，加多少轮都还是垃圾。
</Callout>

<Pitfall title="循环体里没有任何东西在变">
  ```c
  int i = 1;
  while (i <= 5) {
      printf("%d ", i);
  }
  ```
  少了 `i++`，条件永远成立，程序会一直打印 1。
  **判据**：从上往下读一遍循环体，问自己「哪一行会让条件里的变量改变？」——
  一行都找不到，就是死循环，先把推进补上。
</Pitfall>

<Pitfall title="边界差一：该写小于还是小于等于">
  ```c
  while (i < 5) { ... }    /* 跑 4 轮：1 2 3 4 */
  while (i <= 5) { ... }   /* 跑 5 轮：1 2 3 4 5 */
  ```
  不要凭感觉挑。**判据**：手算第一轮和最后一轮的值，看最后一轮是否还满足条件。
  想打印 1 到 5，就必须让 5 通过条件，所以用 `<= 5`。
</Pitfall>

## 这一节的结论

while 的三个角色齐了，循环才停得下来：初始化、条件、推进。
