<KeyPoint>
  break 跳出整个循环，continue 只跳过本轮。它们都只作用于**包含它的那一层**循环——
  写在嵌套循环的内层，就不会影响外层。
</KeyPoint>

## break：够了，别找了

有一类循环天生不必跑完：任务已经完成，再跑下去就是白干。

```c
int i;
for (i = 2; i < n; i++) {
    if (n % i == 0) {
        printf("%d 有因子 %d\n", n, i);
        break;              /* 找到一个就够了，立刻走人 */
    }
}
```

break 一执行，循环立刻结束，程序从循环后面的第一行继续往下走。
它和循环条件无关——是「你主动叫停」，而不是「条件不成立了」。

拿 n = 9 跑一遍，能看清 break 是怎么提前收工的：

| i | `n % i` | 这一轮发生了什么 |
|---|---|---|
| 2 | 1 | 不是因子，继续下一轮 |
| 3 | 0 | 是因子：打印结果并 break，循环当场结束 |

换成 n = 97（素数），同样的循环会一直试到 i = 10，因为条件 `i * i <= n` 不成立才结束。
两种情况都正常，区别只在「谁叫停了循环」：一个是 break，一个是条件。
**能提前结束的循环不要硬跑到底**，这句话后面还会反复用到。

## continue：这一轮跳过，下一轮继续

continue 不停循环，只是**放弃本轮剩下的语句**，直接开始下一轮：

```c
int i;
for (i = 1; i <= 6; i++) {
    if (i % 2 == 0) {
        continue;           /* 偶数：这一轮不打印 */
    }
    printf("%d ", i);
}
```

输出 `1 3 5 `。注意循环总共还是跑了 6 轮，只是其中 3 轮什么都没打印。

<Callout type="warn" title="continue 在 while 里会变成陷阱">
  ```c
  int i = 0;
  while (i < 5) {
      if (i == 2) {
          continue;      /* ❌ i 永远停在 2 */
      }
      printf("%d ", i);
      i++;
  }
  ```
  for 里的 continue 会跳到「推进」那一步（`i++` 照样执行），
  但 while 里的 continue 直接跳回条件判断——而 `i++` 写在它后面，永远轮不到。
  **判据**：在 while 里用 continue 之前，确认推进语句出现在 continue 之前。
</Callout>

## 它们只影响最内层

嵌套循环里，break 只跳出**它所在的那一层**：

```c
int i, j;
for (i = 1; i <= 3; i++) {
    for (j = 1; j <= 3; j++) {
        if (j == 2) {
            break;          /* 只跳出内层，外层照跑 */
        }
        printf("%d%d ", i, j);
    }
}
```

内层在 j = 2 时被打断，所以每个外层轮次只打印了 j = 1 的那一次，
输出是 `11 21 31 `——三组，不是一组。

想一次跳出两层，标准做法是加一个「已经找到」的标志变量，外层也判断一次。
这个套路第 9 章讲函数之后还有更干净的写法，现在知道「break 只管一层」就够了。

判据再强调一遍：break 和 continue 的缩进在哪个花括号里，它的作用范围就到哪里。
写嵌套循环时先想清楚「我要打断的是哪一层」，再决定把这个语句放在哪一行。

<TryIt title="continue 跳过偶数">
{`#include <stdio.h>

int main(void)
{
    int i;

    for (i = 1; i <= 6; i++) {
        if (i % 2 == 0) {
            continue;
        }
        printf("%d ", i);
    }
    printf("\\n");
    return 0;
}
`}
</TryIt>

<Pitfall title="以为内层的 break 能一次跳出两层">
  看到「只跳出一层」的输出（例如本该只有一组结果，却出现了三组），先数一数：**你写 break 的地方在第几层**。
  判据：break 的缩进在哪个 for 的花括号里，它就只结束那一个循环；外层循环变量不受影响。
</Pitfall>

<Pitfall title="同一段逻辑里 continue 和 if 混着用">
  ```c
  for (i = 1; i <= 6; i++) {
      if (i % 2 != 0) {
          printf("%d ", i);
      }
  }
  ```
  和上面的 continue 写法结果一样。两种都可以，但**同一个函数里别混着用**：
  一会儿用 if 包住，一会儿用 continue 提前跳出，读的人就得来回切换思路。
  判据：如果循环体里只有一个 if，优先用 if 包住；如果后面还有一大段代码要跳过，用 continue。
</Pitfall>

## 这一节的结论

break 是「结束整个循环」，continue 是「跳过这一轮」，两者都只管自己所在的那一层。
