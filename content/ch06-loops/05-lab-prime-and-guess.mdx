## 任务一：判断一个数是不是素数

> 读入一个正整数 n，输出 `n 是素数` 或 `n 不是素数`。

素数（质数）是只能被 1 和它自己整除、且大于 1 的整数。2 是最小的素数，1 不是素数。

## 拆解

**第 1 步：先假设它是素数。**

```c
int isPrime = 1;    /* 1 表示是，0 表示不是 */
```

**第 2 步：拿 2、3、4…… 去试除。** 找到一个能整除的因子，就推翻假设，并且**立刻停手**。

```c
for (i = 2; i * i <= n; i++) {
    if (n % i == 0) {
        isPrime = 0;
        break;              /* 结论已经确定，后面不用再试了 */
    }
}
```

**第 3 步：按结论输出。**

两个值得想清楚的细节：

- **为什么找到因子就能停？** 只要 n 有一个除 1 和它自己以外的因子，n 就永远不可能是素数了。继续试除不会改变结论，只会浪费机时。
- **为什么试到 `i * i <= n` 就够？** 如果 n 有因子，必然有一个不超过它的平方根。比如 91 = 7 × 13，试到 7 就抓到了——不用试到 13。

## 完整程序

```c
#include <stdio.h>

int main(void)
{
    int n, i;
    int isPrime = 1;

    scanf("%d", &n);
    if (n < 2) {
        isPrime = 0;            /* 1、0、负数都不是素数 */
    } else {
        for (i = 2; i * i <= n; i++) {
            if (n % i == 0) {
                isPrime = 0;
                break;
            }
        }
    }
    if (isPrime) {
        printf("%d 是素数\n", n);
    } else {
        printf("%d 不是素数\n", n);
    }
    return 0;
}
```

## 任务二：猜数字

> 答案固定为 42。反复读入用户的猜测：猜小了输出 `太小了`，猜大了输出 `太大了`，
> 猜中输出 `猜对了：42` 并结束。

答案固定，程序的行为才是确定的——这正是这一节特意不用随机数的原因：
本站的 C 运行环境是精简的 libc，不保证 `rand` 可用。真想要随机数，可以自己写一个线性同余生成器：
`seed = seed * 1103515245 + 12345;` 之后再取模。

```c
#include <stdio.h>

int main(void)
{
    int secret = 42;
    int guess;

    while (1) {
        scanf("%d", &guess);
        if (guess == secret) {
            printf("猜对了：%d\n", guess);
            break;                  /* 唯一的出口 */
        }
        if (guess < secret) {
            printf("太小了\n");
        } else {
            printf("太大了\n");
        }
    }
    return 0;
}
```

这里的 `while (1)` 是「循环到某件事发生为止」的标准写法：条件永远为真，靠 break 退出。

**判据**：写下 `while (1)` 之后，必须能在循环体里指出那条 break 语句。指不出来，就是死循环。

## 自己动手

1. 把答案改成先读入一个整数（先 `scanf` 答案，再进猜测循环）。
2. 加一个计数器 `int count = 0;`，每次猜测加一，猜中时输出「一共猜了 N 次」。
3. 素数判断里把 `i * i <= n` 改成 `i < n`，用 97 跑一遍——结果一样，但循环多跑了很多轮。

<Pitfall title="找到因子后忘了 break">
  不加 break，程序结果照样对，只是会把 n 一路试除到底。数字小看不出来，
  n 很大时差别就明显了。**判据**：循环体里只要出现「结论已经确定」的赋值（比如 `isPrime = 0`），
  后面就该紧跟一句 break。
</Pitfall>

<Pitfall title="把 1 当成素数">
  如果只写 `for (i = 2; i * i <= n; i++)` 而不先处理 `n < 2`，输入 1 时循环一次都不跑，
  isPrime 保持 1，程序会把 1 判成素数。**判据**：写完任何判断，用 0、1、2 三个边界值各跑一遍。
</Pitfall>

<Pitfall title="while (1) 里没有出口">
  输入用完时 scanf 会一直读失败，`guess` 保持上一次的值，循环就再也退不出去。
  **判据**：看到 `while (1)`，先找 break；找不到就说明这个循环写错了。
</Pitfall>

## 这一节的结论

素数判断用 break 提前结束，猜数字用 break 决定出口——两个程序的骨架都是
「初始化 → 循环 → 用条件收尾」。第 6 章到这里结束：你已经能让程序重复做事，并且知道怎么让它在该停的时候停下来。
