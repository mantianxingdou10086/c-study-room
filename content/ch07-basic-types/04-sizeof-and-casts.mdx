## sizeof 的两种写法

`sizeof` 是一个运算符，不是函数。它可以接一个类型名，也可以接一个表达式：

```c
printf("%d\n", (int)sizeof(int));     /* 接类型名，通常要加括号 */
printf("%d\n", (int)sizeof(x));       /* 接变量，括号可以省 */
```

两种写法给出的都是「占多少字节」。本站统一用 `(int)sizeof(...)` 配 `%d` 打印，原因上一节说过：`size_t` 配 `%zu` 在精简运行环境里不保险。

## 它是编译期算出来的

`sizeof` 要的是**类型的大小**，编译器在编译的时候就知道答案了，根本不需要等到程序跑起来。这一点带来两个可以直接观察的后果：

第一，`sizeof` 不产生运行时开销。写成 `sizeof(int)` 不会在生成的机器码里留下任何计算。

第二，`sizeof` 里的表达式**不会被真的求值**：

```c
int x = 5;
printf("%d\n", (int)sizeof(x++));   /* 打印 4（x 占 4 字节） */
printf("%d\n", x);                  /* 还是 5 —— x++ 没被执行 */
```

编译器只关心 `x` 是什么类型，不关心 `x++` 会做什么。这是 `sizeof` 是编译期运算符的直接证据，也提醒你：**不要在 `sizeof` 里写有副作用的表达式**，那是给自己挖坑。

## 强制转换：改变解释方式

强制转换的写法是把类型名放进括号，放在表达式前面：

```c
int n = (int)3.99;
```

`3.99` 是 `double`，`(int)` 让编译器按整数的方式去处理它。结果是 **3**，不是 4——浮点转整数是**截断**（丢掉小数部分，向零取整），不是四舍五入。负数也一样：`(int)-3.99` 是 `-3`。

要强调的是：强制转换不改变那串比特本身，它改变的是「接下来按什么类型解释它」。整数和浮点的内存排布完全不同，所以浮点转整数时编译器确实要生成一段真正的转换代码；但整数之间的转换（比如 `(char)65`）在底层就是同一串比特，只是换个类型名去看它。

## 整数除法这个老朋友

强制转换最常见的用途，是修一个你已经见过的坑：

```c
printf("%d\n", 7 / 2);             /* 3   —— 两个 int 相除，结果还是 int */
printf("%.2f\n", (double)7 / 2);   /* 3.50 —— 先把 7 转成 double */
```

`(double)7 / 2` 里，`7` 先被转成 `7.0`，于是这次除法是浮点除法。这和写 `7 / 2.0` 效果一样，只是把「我要浮点结果」这个意图写得更显眼。

<TryIt title="截断、强制转换与整数除法">
{`#include <stdio.h>

int main(void)
{
    double x = 3.99;
    int n = (int)x;

    printf("(int)3.99 = %d\\n", n);
    printf("7 / 2 = %d\\n", 7 / 2);
    printf("(double)7 / 2 = %.2f\\n", (double)7 / 2);
    printf("sizeof(double) = %d\\n", (int)sizeof(double));
    return 0;
}
`}
</TryIt>

## typedef：给类型起个别名

`typedef` 用来给一个类型起新名字：

```c
typedef unsigned int uint;
typedef double Money;
```

之后 `uint x;` 和 `unsigned int x;` 完全等价——`typedef` 不创建新类型，只是起个别名。什么时候值得用？当这个别名能让代码更容易读的时候：`Money price;` 比 `double price;` 更清楚地说明「这是金额」。

<Pitfall title="以为 (int)3.99 是 4">
  浮点转整数是截断，不是四舍五入。判据：只要你想要「四舍五入到整数」，
  就必须自己加半个单位，比如 `(int)(3.99 + 0.5)` 才得到 4。
  不加这一步，代码在 3.99 上给出 3，在你测试时用的 3.5 上也给出 3，很难发现。
</Pitfall>

<Pitfall title="只在一边加转换">
  ```c
  printf("%.2f\n", (double)(7 / 2));   /* ❌ 先算出 3，再转成 3.00 */
  ```
  括号的位置决定一切：转换写在括号**里面**的除法之前才有用。
  判据：看到 `(double)` 后面紧跟一个括号包住的表达式，就先确认这个转换到底作用在谁身上。
</Pitfall>
