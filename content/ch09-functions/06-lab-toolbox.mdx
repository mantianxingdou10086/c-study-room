## 任务

> 写一个小工具库，读入一个整数 `n`，输出两行：
> 第一行是 `n` 的各位数字之和（`17` 就是 `1 + 7 = 8`）；
> 第二行判断它是不是素数——是就输出 `prime`，不是就输出 `composite`。
>
> 要求：「各位数字之和」和「判断素数」各写成一个函数，`main` 里只做读入、调用、打印。

输入 `17`，期望输出：

```
8
prime
```

## 动手之前先问三个问题

真正开始写之前，花一分钟回答这三个问题，能省掉后面很多返工：

1. **这段逻辑能用一句话说清吗？** 能，就适合当函数（比如「各位数字之和」）。说不清，说明它其实是好几件事，得再拆。
2. **它的输入是什么、输出是什么？** 输入就是参数表，输出就是返回类型。这两样定下来，函数名和原型自然就写出来了——先写原型、后写函数体，正是这个道理。
3. **它需要改调用方的数据吗？** 不需要就用 `return` 把结果交回去；需要（比如往数组里写）就把数组当参数传进来，并且在名字里说清楚——`fill_zeros`、`add_all` 这种名字本身就在提醒读代码的人「这个函数会动你的数据」。

## 拆解

**第 1 步：先把「要做哪几件事」写成函数原型**

动手写代码之前，先决定要哪几个函数。这一步决定了 `main` 最终长什么样：

```c
int digit_sum(int n);   /* 交回 n 的各位数字之和 */
int is_prime(int n);    /* n 是素数交回 1，否则交回 0 */
```

两个原型都写在 `main` 前面，函数体放到后面。这样 `main` 一上来就是「读入 → 调用 → 打印」，读代码的人不用先看一堆循环。

**第 2 步：digit_sum —— 取末位、扔掉末位**

第 4 章学过的套路：`n % 10` 拿到末位，`n / 10` 把末位扔掉，两者重复到 `n` 变成 0：

```c
int digit_sum(int n)
{
    int s = 0;

    while (n > 0) {
        s = s + n % 10;
        n = n / 10;
    }
    return s;
}
```

这里 `n` 是形参，是副本——函数里把 `n` 除到 0 不会影响调用方。累加变量 `s` 必须先赋初值 0，否则加进去的是垃圾值。

**第 3 步：is_prime —— 从 2 试到根号 n**

素数是「除了 1 和它自己，没有别的约数」的数。所以从 2 开始一个个试，只要找到一个能整除 `n` 的，就说明它不是素数，可以立刻返回 0：

```c
int is_prime(int n)
{
    int i;

    if (n < 2) {
        return 0;               /* 0 和 1 都不是素数 */
    }
    for (i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            return 0;
        }
    }
    return 1;
}
```

两个细节：

- 循环条件写 `i * i <= n`，等价于「试到根号 n」。`n` 如果有一个大于根号 n 的约数，那一定还有一个小于根号 n 的配对它，所以试到根号就够。这里用乘法代替开方，就不需要 `math.h` 了。
- 第一行那个 `if (n < 2) return 0;` 不能省：`n` 是 0 或 1 时循环一次都不会进，函数会一路走到最后返回 1——把 1 说成素数。

**第 4 步：main 只做三件事**

```c
int main(void)
{
    int n;

    scanf("%d", &n);
    printf("%d\n", digit_sum(n));
    if (is_prime(n)) {
        printf("prime\n");
    } else {
        printf("composite\n");
    }
    return 0;
}
```

读入、调用、打印。`main` 里没有 `%`、没有 `while`——所有「怎么算」的东西都已经搬进函数了。

## 完整程序

```c
#include <stdio.h>

int digit_sum(int n);
int is_prime(int n);

int main(void)
{
    int n;

    scanf("%d", &n);
    printf("%d\n", digit_sum(n));
    if (is_prime(n)) {
        printf("prime\n");
    } else {
        printf("composite\n");
    }
    return 0;
}

int digit_sum(int n)
{
    int s = 0;

    while (n > 0) {
        s = s + n % 10;
        n = n / 10;
    }
    return s;
}

int is_prime(int n)
{
    int i;

    if (n < 2) {
        return 0;
    }
    for (i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            return 0;
        }
    }
    return 1;
}
```

注意文件里的顺序：包含头文件 → 函数原型 → `main` → 各函数的实现。第 10 章会把这条惯例讲全。

## 自己动手

函数最大的好处是「一处写、处处用」。下面这段程序没有多写一行判断逻辑，只是把 `is_prime` 放进循环里，一次就查了 11 个数：

<TryIt title="同一组函数处理一串数字">
{`#include <stdio.h>

int digit_sum(int n)
{
    int s = 0;

    while (n > 0) {
        s = s + n % 10;
        n = n / 10;
    }
    return s;
}

int is_prime(int n)
{
    int i;

    if (n < 2) {
        return 0;
    }
    for (i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            return 0;
        }
    }
    return 1;
}

int main(void)
{
    int i;

    for (i = 10; i <= 20; i++) {
        printf("%d %d %d\\n", i, digit_sum(i), is_prime(i));
    }
    return 0;
}
`}
</TryIt>

输出三列：数字、各位数字之和、是否素数。数一数 `1` 那一列出现的位置——13、17、19，正是 10 到 20 之间的三个素数。挑两个数手算一遍，再和输出对。

<Pitfall title="1 被当成素数">
  `is_prime` 里如果只有「从 2 试到根号 n」的循环，`n` 是 1 时循环一次都不进，函数会一路走到末尾返回 1——把 1 说成素数。
  **判据**：只要函数开头没有 `if (n < 2) { return 0; }`，1 和 0 就一定会被误判成素数。
</Pitfall>

<Pitfall title="循环条件写成 i 小于等于 n">
  `for (i = 2; i <= n; i++)` 也能算出正确答案，但会白做很多次除法：`i` 一旦超过 `n` 的一半，就不可能再整除了。
  **判据**：判断素数的循环条件里出现 `i <= n`，就换成 `i * i <= n`。既能算对，又省掉一多半的循环。
</Pitfall>

<Pitfall title="main 里又长出了细节">
  抽函数最常见的失败方式是「抽了一半」：函数写了，`main` 里还留着几行 `while` 和 `%`。
  **判据**：`main` 超过 15 行、或者里面出现了 `%`、`while` 这类「怎么算」的东西，说明还有逻辑没搬出去。搬干净的标准是——只读 `main`，你就能说出这个程序做了哪几件事。
</Pitfall>

## 这一节的结论

这一章从「为什么要函数」走到「自己写一个小工具库」，中间只加了一条规则：**函数拿到的是副本**。值传递决定了普通参数改不动原件，数组参数因为传的是首元素地址所以改得动；`return` 负责交回结果，也负责提前结束；递归只是「函数调用自己」加上一个能停下来的条件。
