<KeyPoint>
  函数把「做什么」和「怎么做的细节」分开：调用处只写函数名，细节收在函数体里。
  这是控制复杂度的第一件工具——程序变长之后，它决定你还读不读得懂自己写的代码。

## 你早就在用函数了

`printf("hello\n");` 就是一个函数调用：`printf` 是函数名，括号里的东西是交给它的参数，它负责把内容打到屏幕上。你从来没有看过 `printf` 内部是怎么实现的——这正是函数的价值：**你知道它能做什么，不需要知道它怎么做。**

`main` 也是一个函数，只是它比较特殊：程序从它开始执行。所以「写程序」这件事，本质就是写一堆函数，再让它们互相调用。

## 一个函数由四部分组成

自己定义一个函数，写起来就这几样东西：

```c
int area(int w, int h)
{
    return w * h;
}
```

从上往下读：

| 位置 | 名字 | 作用 |
|---|---|---|
| `int` | 返回类型 | 函数算完之后交给调用方的值是什么类型 |
| `area` | 函数名 | 调用时用的名字 |
| `(int w, int h)` | 参数表 | 调用方要交进来几个值、分别是什么类型 |
| `{ return w * h; }` | 函数体 | 「怎么算」的细节，全在这里 |

调用它只要一行：

```c
int s = area(3, 4);
```

`3` 和 `4` 叫**实参**，是调用方交进去的具体值；函数定义里的 `w` 和 `h` 叫**形参**，是函数体里用来接住这些值的名字。两者靠**位置**对应：第一个实参交给第一个形参，所以 `w` 拿到 3、`h` 拿到 4，算出 12，由 `return` 交回调用方。

<Callout type="info" title="形参和实参只是位置对应">
  形参的名字和实参的名字没有任何关系，甚至不需要是变量：`area(3, 4)` 直接把数字写进括号里也完全合法。
  换个名字调用，只要位置对得上，结果就一样：`area(a, b)` 里 `w` 拿 `a`、`h` 拿 `b`。
</Callout>

## 重复的代码是抽函数的信号

什么时候该写函数？判据很直接：**同一段代码在程序里出现了第二次。**

假设你要打一张小票，中间要打两条一样的分隔线：

```c
printf("================\n");
printf("area = %d\n", 12);
printf("================\n");
```

以后想把 `=` 换成 `-`，两处都要改；出现三处就要改三处，漏一处就是不一致的界面。抽成函数之后，这条规则只写一遍：

<TryIt title="把重复的代码抽成一个函数">
{`#include <stdio.h>

void print_sep(void)
{
    printf("================\\n");
}

int area(int w, int h)
{
    return w * h;
}

int main(void)
{
    print_sep();
    printf("area = %d\\n", area(3, 4));
    print_sep();
    return 0;
}
`}
</TryIt>

注意 `print_sep` 的返回类型写的是 `void`：它只负责打印，不需要交回任何值。空参数表写成 `(void)`，意思是「这个函数不要参数」。

## 函数要写在调用的前面

上面这段程序里，`print_sep` 和 `area` 都写在 `main` 的前面。如果你把它们的定义挪到 `main` 后面，编译器读到 `main` 里的 `print_sep()` 时还不知道这个函数长什么样，会直接报错。

两种解决办法：

1. 定义写在前面——短程序这么写最省事。
2. 在 `main` 前面先写一行**函数原型**，把定义放到文件后面：

```c
int area(int w, int h);   /* 原型：只写返回类型、名字、参数类型 */
```

原型末尾有分号，函数体在别处。原型的作用是提前告诉编译器「有这么个函数、它收什么、它给什么」，这样 `main` 里就能先用后定义。第 10 章会把「谁写在哪」整理成一个固定顺序。

<Pitfall title="函数名后面多写了分号">
  写定义时手一滑写成 `int area(int w, int h);` 然后直接跟 `{`，编译器会把它当成原型声明，再抱怨后面那个 `{` 没有意义。
  判据：报错信息里出现「expected declaration」，或者错误行指着函数体的第一行，就先回头看函数名那一行的末尾有没有多余的分号。
</Pitfall>

<Pitfall title="以为函数能直接看见调用方的变量">
  函数体里只认两样东西：自己的形参，和自己在函数体里声明的变量。在 `area` 里写 `return w * x;` 会直接编译失败——`x` 是 `main` 的变量，函数看不见。
  判据：报「未声明的标识符」时，先问「这个名字是参数表里的吗？是在这个函数体里声明的吗？」两个都不是，就说明你想用外面的数据——那它必须**作为参数传进来**。
</Pitfall>

## 这一节的结论

函数就三件事：定义（返回类型 + 名字 + 参数表 + 函数体）、调用（名字加一对括号）、参数按位置一一对应。抽函数的信号是「同一段代码出现了第二次」，而写函数的收益是——以后改规则只改一处。

不过你可能已经注意到一个奇怪的地方：函数里对参数做了什么，外面的变量好像一点反应都没有。这不是错觉，是 C 语言里最重要的一条规则。下一节专门讲它。
