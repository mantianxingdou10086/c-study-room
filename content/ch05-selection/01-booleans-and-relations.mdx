<KeyPoint>
  C 里没有真正的布尔类型（传统写法）：0 是假，非 0 都是真——包括 -1。
  这一节先把「真」和「假」这两个词从数学里的概念，换成一个具体的整数。
</KeyPoint>

## 关系运算符就是一道判断题

`>`、`<`、`>=`、`<=`、`==`、`!=` 这六个符号你早就认识，它们叫关系运算符，做的事就是「比一比」。

| 写法 | 问的问题 | 例子 | 结果 |
|---|---|---|---|
| `a == b` | 相等吗 | `5 == 5` | 1 |
| `a != b` | 不相等吗 | `5 != 5` | 0 |
| `a > b` | 大于吗 | `7 > 3` | 1 |
| `a >= b` | 大于或等于吗 | `3 >= 7` | 0 |
| `a < b` | 小于吗 | `3 < 7` | 1 |
| `a <= b` | 小于或等于吗 | `7 <= 7` | 1 |

注意最后一列：结果不是「真」「假」两个字，而是整数 `1` 和 `0`。成立得 `1`，不成立得 `0`。
所以 `printf("%d\n", 5 > 3)` 能打印出东西——它打印的就是这个整数。

## 真与假：只看是不是 0

既然比较的结果是整数，C 判断真假的标准就非常朴素：

- 值是 `0` → 假
- 值是任何**非 0** 的数 → 真

`if` 后面括号里的东西会被当成「一个值」来看，它只问一件事：**这个值等于 0 吗**。
所以 `-1` 在 C 里是真，`0.5` 是真，`'A'`（也就是 65）也是真。只有 `0` 是假。

这解释了一个新手常踩的坑：`if (-1)` 会进那个分支，因为 `-1` 不是 `0`。
C 里的「真」不是「正数」，而是「不是零」。

<Callout type="info" title="后来的标准有 _Bool，但规则没变">
  C99 引入了 `_Bool` 类型，`stdbool.h` 里还给了 `true` 和 `false` 两个宏（它们的值就是 `1` 和 `0`）。
  但底层判断规则一直是「0 是假、非 0 是真」，所以你先学传统写法完全不吃亏——
  而且读别人的老代码时，你必须知道这条规则。
</Callout>

## 一个可以跑的实验

下面这段程序把关系运算的结果直接打印出来，又顺手验证了 `-1` 的命运。

<TryIt title="关系运算到底算出什么">
{`#include <stdio.h>

int main(void)
{
    int a = 7, b = 7;

    printf("%d %d %d\\n", a > b, a == b, a != b);

    if (-1)
        printf("-1 在 if 里算真\\n");
    else
        printf("-1 在 if 里算假\\n");
    return 0;
}
`}
</TryIt>

试着把 `int a = 7, b = 7;` 改成 `int a = 3, b = 7;`，先自己写下三个数字，再跑一次对照。

<Pitfall title="把 = 当成 ==">
  `if (x == 5)` 是比较，`if (x = 5)` 是先把 5 赋给 `x`、再拿整个表达式的值（也就是 5）去判断——
  结果这个分支**永远会进**，而且编译器往往不报错，只给个警告。
  判据：看到条件里只有一个等号，就停下来数一遍——比较要两个。
</Pitfall>

<Pitfall title="把数学里的连写比较照搬过来">
  `if (0 < n < 10)` 看着像「n 在 0 到 10 之间」，实际不是。
  C 从左往右算：`0 < n` 先得到一个 `0` 或 `1`，再拿这个 `0`/`1` 去和 `10` 比——而 `0` 和 `1` 都小于 `10`，
  所以这个条件**永远成立**。要表达区间必须写成两个条件：`n > 0 && n < 10`（下一节讲 `&&`）。
</Pitfall>

## 这一节的结论

关系运算给你一个整数：成立是 `1`，不成立是 `0`；而 `if` 只认「是不是 0」。
记住这两句话，你就能解释所有「为什么这里进去了 / 为什么没进去」的疑问。
