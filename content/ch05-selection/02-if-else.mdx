<KeyPoint>
  多路分支的顺序很重要：条件要从最特殊写到最一般，否则后面的分支永远进不去。
  这一节的核心不是语法，是「谁先判断」。
</KeyPoint>

## 三种形状

最简单的形式，条件成立就执行下面那一句，不成立就跳过：

```c
if (score >= 60)
    printf("及格\n");
```

想同时处理「不成立」的情况，加一个 `else`：

```c
if (score >= 60)
    printf("及格\n");
else
    printf("不及格\n");
```

要分成多档，就在中间串 `else if`：

```c
if (score >= 90)
    printf("优秀\n");
else if (score >= 60)
    printf("及格\n");
else
    printf("不及格\n");
```

这三个分支是**从上往下依次检查**的。一旦某个条件成立，程序进入那个分支、执行完里面的语句，
然后**整个结构就结束了**——后面的条件连看都不看一眼。

## 顺序决定结果

把上面那段代码的两个条件对调一下，结果完全不同：

```c
if (score >= 60)
    printf("及格\n");
else if (score >= 90)
    printf("优秀\n");
```

95 分进来，第一个条件 `score >= 60` 就成立，程序打印「及格」就走了。
`else if (score >= 90)` 永远不会被检查到——它变成了**死代码**：写得没错，但永远跑不到。

所以写多路分支时，每写一个条件就问自己一句：**哪个条件更特殊？**
「更特殊」的意思是满足它的情况更少。`>= 90` 只有 90~100 这一段，比 `>= 60` 特殊，所以它必须排在前面。

一句话记法：**从最特殊写到最一般。**

## else 和谁配对

缩进是给人看的，编译器不看。规则只有一条：**`else` 属于前面最近的、还没有配对的 `if`**。

```c
if (a > 0)
    if (b > 0)
        printf("A\n");
else
    printf("B\n");     /* 这个 else 配的是 if (b > 0)，不是 if (a > 0) */
```

按缩进看，它像是配外层的 `if (a > 0)`；按规则，它配内层的 `if (b > 0)`。
这就是有名的「悬挂 else」问题。想让 `else` 配外层，只能加花括号把它隔开：

```c
if (a > 0) {
    if (b > 0)
        printf("A\n");
} else {
    printf("B\n");
}
```

<Callout type="tip" title="不确定就加花括号">
  花括号不花什么代价，却能消灭整整一类「看起来对、跑起来错」的问题。
  分支体超过一行、或者里面还有 if，就顺手加上。
</Callout>

<TryIt title="把顺序换一下，看谁进得去">
{`#include <stdio.h>

int main(void)
{
    int score = 95;

    if (score >= 90)
        printf("先判最特殊：优秀\\n");
    else if (score >= 60)
        printf("先判最特殊：及格\\n");
    else
        printf("先判最特殊：不及格\\n");

    if (score >= 60)
        printf("顺序反了：及格\\n");
    else if (score >= 90)
        printf("顺序反了：优秀\\n");
    return 0;
}
`}
</TryIt>

第二段里那句 `优秀` 永远不会打印——95 分这么高都不行，别的分数更不行。

<Pitfall title="把最一般的条件放在最前面">
  看到 `if (x >= 60)` 出现在 `if (x >= 90)` 前面，就说明顺序反了。
  判据：**逐个检查每个分支的条件，看它是不是被前面某个分支「吃掉」了**——
  如果前一个条件成立时后一个条件也必然成立，那后一个分支就是死代码。
</Pitfall>

<Pitfall title="else 后面忘了 if">
  写 `else (score > 0)` 是编译错误：`else` 后面只能直接跟一条语句，条件必须写成 `else if (score > 0)`。
  判据：`else` 后面如果紧跟一个圆括号，而括号前面没有 `if`，那就是漏写了。
</Pitfall>

## 这一节的结论

`if / else if / else` 是一排从上往下开的门，进去一扇后面的门就关上了。
写的时候先排特殊条件、再排一般条件，最后用 `else` 兜底。
