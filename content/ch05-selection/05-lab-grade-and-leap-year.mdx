## 任务一：成绩等级

> 读入一个整数成绩（0~100），输出它的等级：
> 90 及以上 `A`、80~89 `B`、70~79 `C`、60~69 `D`、60 以下 `F`。

动手前先把边界一条条列出来，这一步比写代码重要：

| 分数段 | 等级 | 这个分支要写的条件 |
|---|---|---|
| 90 ~ 100 | A | `score >= 90` |
| 80 ~ 89 | B | `score >= 80` |
| 70 ~ 79 | C | `score >= 70` |
| 60 ~ 69 | D | `score >= 60` |
| 0 ~ 59 | F | 剩下的都是 |

注意最后一列：每个分支只需要写下界，**上界由前一个分支挡住了**。
85 分走到 `>= 80` 那一行时，程序已经知道它不满足 `>= 90`，所以「80~89」这个区间是自动形成的。

```c
if (score >= 90)
    printf("A\n");
else if (score >= 80)
    printf("B\n");
else if (score >= 70)
    printf("C\n");
else if (score >= 60)
    printf("D\n");
else
    printf("F\n");
```

最后那个 `else` 不写条件，它接住所有剩下的情况（包括负数这种非法输入——
真实程序要在前面加一道范围检查，这一节先只关心分档）。

## 任务二：闰年

> 读入一个年份，是闰年输出 `yes`，否则输出 `no`。

闰年的规则要背准确：**能被 400 整除，或者能被 4 整除但不能被 100 整除**。

这条规则里藏着一个例外：1900 能被 4 整除，但它**不是**闰年，因为它能被 100 整除、又不能被 400 整除。
所以判断顺序必须这样排：

1. `y % 400 == 0` → 闰年（例：2000）
2. 否则 `y % 100 == 0` → 平年（例：1900、2100）——这就是那个例外
3. 否则 `y % 4 == 0` → 闰年（例：2024）
4. 否则 → 平年（例：2023）

第 2 步是全部的关键：它必须排在「能被 4 整除」**前面**。
如果先判 `y % 4 == 0`，1900 在那里就被判成闰年，后面再写什么条件都没机会执行了。

## 完整程序

```c
#include <stdio.h>

int main(void)
{
    int y;

    scanf("%d", &y);
    if (y % 400 == 0)
        printf("yes\n");
    else if (y % 100 == 0)
        printf("no\n");
    else if (y % 4 == 0)
        printf("yes\n");
    else
        printf("no\n");
    return 0;
}
```

## 自己动手

把输入换成 `2000`、`2024`、`2023`、`2100`，**先写下你的预判**，再逐个跑一遍。
预判和结果不一致的那些年份，就是你还理解得不够牢的地方。

<Pitfall title="边界差一分就错档">
  90 分应该算 A。如果把条件写成 `score > 90`，90 分就被挤到 B 档去了。
  判据：**把每个档位的端点值代进去跑一遍**——90、89、80、60、59 各跑一次，比读十遍代码都管用。
</Pitfall>

<Pitfall title="闰年只判了能被 4 整除">
  只写 `y % 4 == 0` 会判错 1900、2100 这类整百年份。
  判据：看到 `% 4` 单独出现、旁边没有 `% 100` 和 `% 400`，就是漏了整百年的例外。
</Pitfall>

## 这一节的结论

两个程序、同一套方法：**先列边界，再排顺序**。
列边界时你其实是在用自然语言想清楚需求，排顺序时你才在写代码——
这一步没做，写出来的分支不是漏档就是永远进不去。

到这里，你的程序已经会「选一条路走」了。下一章的问题是：**同一条路怎么走很多遍**——循环。
