<KeyPoint>
  变量是内存里的一块空间，名字只是它的标签。声明是「向编译器申请这块空间」，
  赋值是「把值放进去」——这两件事可以分开做，也可以合成一句。
</KeyPoint>

## 从「盒子」说起

初学者最容易接受的比喻是：变量就是一个盒子，盒子上贴着名字，里面装着值。

```c
int age;        /* 声明：向编译器要一个能装整数的盒子，标签写 age */
age = 20;       /* 赋值：把 20 放进去 */
```

也可以一行写完：

```c
int age = 20;   /* 声明 + 初始化 */
```

<Callout type="info" title="「初始化」和「赋值」不是一回事">
  初始化是**盒子造出来的时候**就放进去的第一个值；赋值是**之后**再放。
  区别在 C 里很重要：没初始化的局部变量里装的是**垃圾数据**（内存里原来剩什么就是什么），
  读它不会报错，只会得到莫名其妙的结果。
</Callout>

## 盒子比喻的边界：变量不是容器，是位置

比喻有个地方会骗人：**赋值不是「把值搬进去」，而是「把那个位置的内容改成新值」**。

```c
int a = 3;
int b = a;    /* 把 a 当时的值（3）抄一份给 b */
a = 7;        /* 改的是 a 那块位置，b 完全不受影响 */
```

执行完这三行：`a` 是 7，`b` 还是 3。

这一点后面会反复用到（尤其是第 9 章「值传递」和第 11 章指针）：
**C 里的赋值和传参，默认都是复制值，不是共享**。想共享同一个东西，得用地址——那是指针要解决的事。

<TryIt title="亲手验证：改 a 不影响 b">
{`#include <stdio.h>

int main(void)
{
    int a = 3;
    int b = a;

    a = 7;
    printf("a = %d, b = %d\\n", a, b);
    return 0;
}
`}
</TryIt>

## 常见的数据类型（第 7 章细讲）

现在只需要记住三种最常用的：

| 写法 | 装什么 | 例子 |
|---|---|---|
| `int` | 整数 | `int count = 42;` |
| `double` | 小数 | `double price = 9.9;` |
| `char` | 单个字符 | `char grade = 'A';` |

注意 `char` 的值要用**单引号**：`'A'` 是字符，`"A"` 是字符串（完全不同的东西，第 13 章讲）。

## 变量要先声明再用

C 是「先声明后使用」的语言。用了没声明的名字，编译器直接报错：

```
error: 'score' undeclared (first use in this function)
```

<Pitfall title="用了没初始化的变量">
  ```c
  int sum;
  printf("%d\n", sum);   /* 打印的是垃圾值，不是 0 */
  ```
  C 不会替你清零。**声明时就顺手给个初值**是个好习惯：
  `int sum = 0;`。累加类变量尤其要注意——不初始化，你的和会从一个随机数开始。
</Pitfall>

<Pitfall title="把赋值写成数学等式">
  `a = b` 在 C 里的意思是「把 b 的值赋给 a」，不是「a 和 b 相等」。
  想知道相等要用 `==`（第 5 章）。写成 `if (a = b)` 是经典事故：它永远为真，而且悄悄改了 a。
</Pitfall>
