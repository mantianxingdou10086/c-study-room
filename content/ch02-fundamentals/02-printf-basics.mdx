<KeyPoint>
  printf 的第一个参数是**模板**，里面的 `%d` 这类占位符会被后面的参数按顺序替换。
  模板里的普通文字原样输出，`\n` 表示换行。
</KeyPoint>

## 模板 + 参数

```c
printf("我今年 %d 岁\n", 20);
```

拆开看：

| 部分 | 作用 |
|---|---|
| `"我今年 %d 岁\n"` | 格式串（模板）：普通文字照原样打印，`%d` 是占位符 |
| `20` | 参数：按顺序填进占位符 |
| `\n` | 转义字符：换行 |

多个占位符就按顺序对应多个参数：

```c
int x = 4, y = 6;
printf("%d+%d=%d\n", x, y, x + y);   /* 4+6=10 */
```

参数可以是变量，也可以是表达式（`x + y` 会先算出来再填进去）。

## 常用转换说明

| 占位符 | 用于 | 例子 |
|---|---|---|
| `%d` | 整数 | `printf("%d", 42)` → `42` |
| `%f` | 小数 | `printf("%f", 3.5)` → `3.500000` |
| `%.2f` | 小数，保留 2 位 | `printf("%.2f", 3.5)` → `3.50` |
| `%c` | 单个字符 | `printf("%c", 'A')` → `A` |
| `%s` | 字符串 | `printf("%s", "hi")` → `hi` |

注意 `%f` 默认打印**6 位小数**——这就是为什么「输出 3.5」写成 `%f` 会得到 `3.500000`。
想控制位数就用 `%.2f` 这种写法（第 3 章细讲宽度与精度）。

## 最危险的一点：类型不匹配不报错

```c
double price = 9.9;
printf("%d\n", price);   /* ❌ 编译能过（最多警告），打印出来是垃圾 */
```

`%d` 告诉 printf「这个参数是整数」，但实际传进去的是浮点数——两者在内存里的排布不同，
printf 会按整数的方式去解释那串二进制，结果就是一个毫无意义的数字。

<Callout type="warn" title="规则：占位符必须和参数类型对得上">
  `int` → `%d`，`double` → `%f`，`char` → `%c`，字符串 → `%s`。
  对不上时程序**不一定崩溃**，只是安静地打印垃圾——这是最难查的一类问题。
</Callout>

<TryIt title="改一改：让输出变成「我今年 20 岁」">
{`#include <stdio.h>

int main(void)
{
    int age = 20;

    printf("我今年 %d 岁\\n", age);
    printf("明年我 %d 岁\\n", age + 1);
    return 0;
}
`}
</TryIt>

<Pitfall title="忘了写 \n，所有输出挤成一行">
  printf 不会自动换行。两次 printf 之间没有 `\n`，输出就连在一起。
  调试时如果看到「结果都粘在一行」，先检查是不是漏了 `\n`。
</Pitfall>

<Pitfall title="占位符数量和参数数量不一致">
  `printf("%d %d\n", 5);` 只有一个参数却有两个占位符——第二个占位符会去读不存在的东西，
  打印出随机值。参数个数必须和占位符个数一致。
</Pitfall>
