<KeyPoint>
  C 是一门「贴近机器的高级语言」：写法上是高级语言（有变量、函数、循环），
  但内存怎么用、什么时候释放，全部由你负责。这既是它的难点，也是它五十年不倒的原因。
</KeyPoint>

## 先从「你在跟谁打交道」说起

写 Python 的时候，你在跟**解释器**打交道：你写 `x = 1`，解释器替你想好在哪儿放这个 1，用完了还替你收走。

写 C 的时候，你在跟**内存**打交道：你说「给我一块能放整数的空间，我要叫它 x」，编译器就真的去安排一块内存，`x` 只是这块内存的名字。用完不还，它就一直是你的——程序占着不放，直到退出。

这个差别决定了后面所有事情：为什么 C 快、为什么 C 难、为什么 C 能写操作系统。

## C 今天还在哪些地方

如果只看「新项目用什么语言」的排行榜，C 看起来像个老人家。但换个角度看：

| 场景 | 为什么是 C |
|---|---|
| 操作系统内核 | Linux 内核绝大部分是 C——它要直接管内存、管硬件，中间不能有翻译层 |
| 嵌入式与单片机 | 空调、洗衣机、无人机飞控、机器人下位机：内存可能只有几 KB，容不下运行时 |
| 数据库与缓存 | SQLite、Redis 的核心是 C：需要精确控制内存与磁盘 I/O |
| 其他语言的运行时 | Python 的解释器、Java 虚拟机的底层、你用的 `numpy`，核心都是 C 或 C++ |
| 机器人/视觉/自动驾驶 | 实时性要求高的感知与控制模块：每毫秒要跑完，不能等垃圾回收 |

你在机器人队里见到的那种「上位机跑 Python 调参、下位机跑 C 控电机」的分工，就是这个道理：**C 负责确定性，Python 负责方便**。

## 学 C 你能得到什么

<Callout type="tip" title="这是最实在的收获">
  学 C 最大的价值不是「会用 C 写项目」，而是**你终于知道其他语言替你做了什么**。
  学完 C 再看 Python 的 `list.append`，你会想到「这背后可能是扩容 + 拷贝」；
  看 Java 的垃圾回收，你会明白「它在替我还我手动还过无数次的那种内存」。
</Callout>

具体一点：

1. **内存不再是黑盒**。你知道变量存在哪儿、数组为什么按下标随机访问很快、字符串为什么要有个结尾标记。
2. **编译、链接、库这些词变成实物**。你会真的经历「一个符号找不到」的链接错误，而不是背概念。
3. **看得懂别人的底层代码**。看开源库、看芯片手册里的示例、看学长留下的驱动代码，不再两眼一抹黑。

## 也要提前告诉你：难点在哪

<Callout type="warn" title="C 的陡坡在前半段">
  前几章你会觉得「就这？」——变量、循环、函数，和别的语言差不多。
  真正的坡在**第 11 章指针**开始：如果那里没走稳，后面全部会塌。
  所以本站的节奏是：前面把「数据在内存里长什么样」反复讲透，指针那一章才好过。
</Callout>

还有两个心理准备：

- **报错信息不友好**。C 的编译器会说「expected ';' after expression」而不是「你忘了写分号」。第 4 节我们专门练读报错。
- **没有安全网**。数组越界不会报错，用未初始化的变量不会报错，它们只会让程序「莫名其妙地」出错。这也是为什么本站反复强调「先想清楚，再写」。

## 先看一眼真实的 C 程序

下面这段是能跑的，点「运行」试试（第一次会需要下载编译器，约 34 MB，之后就走缓存了）：

<TryIt title="第一个能跑的程序" stdin="3">
{`#include <stdio.h>

int main(void)
{
    int age;

    printf("你今年几岁？请输入一个整数：");
    scanf("%d", &age);
    printf("明年你就 %d 岁了。\\n", age + 1);
    return 0;
}
`}
</TryIt>

现在你不需要看懂每一行——`#include`、`int main(void)`、`scanf` 里的 `&`，后面几节都会讲。
先感受一件事：**这段代码做的事情，和你按下「运行」后看到的事情，是完全对应的，没有黑魔法**。

<Pitfall title="别掉进「哪门语言最好」的争论">
  语言是工具。C 适合「要快要省要可控」的活，Python 适合「要快写完」的活。
  学 C 的目标是让你**多一种能力**，而不是让你以后只写 C。
  所以看到「C 已经过时了」这类说法，直接跳过——排行榜和内核代码是两个世界。
</Pitfall>

## 这一节的结论

C 的价值在于**它不替你做决定**：内存你来管、硬件你来碰、开销你来算。
