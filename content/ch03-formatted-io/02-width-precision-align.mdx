<KeyPoint>
  `%` 和转换说明之间可以塞两个数字：`%宽度.精度说明符`。
  宽度管「这一列占几个字符」，精度管「小数点后几位」——表格对齐全靠它。
</KeyPoint>

## 宽度：这一列占多宽

```c
printf("%5d|\n", 42);
```

输出是 `   42|` —— 42 只占 2 个字符，所以左边补 3 个空格凑够 5 个字符宽。

| 写法 | 输出 | 说明 |
|---|---|---|
| `%5d` | `   42` | 右对齐（默认），左边补空格 |
| `%-5d` | `42   ` | 左对齐，右边补空格 |
| `%05d` | `00042` | 用 0 填充（常用于编号、时间） |
| `%1d` | `42` | 宽度不够时**不会被截断**，只是按实际宽度输出 |

<Callout type="tip" title="宽度不够会怎样">
  `%2d` 打印 42 时，输出还是 `42`（2 位）——宽度是「最小宽度」，
  不是「最多几个字符」。这一点和第 3 章后面的 `%.2s`（字符串截断）不一样，别搞混。
</Callout>

## 精度：小数点后几位

```c
printf("%.2f\n", 3.14159);   /* 3.14 */
printf("%.4f\n", 3.14159);   /* 3.1416  ← 四舍五入 */
printf("%.0f\n", 3.14159);   /* 3       ← 没有小数点 */
```

精度是**四舍五入**，不是直接砍掉后面的位。这一点在成绩、金额这类场景很重要。

## 宽度和精度可以一起写

```c
printf("%8.2f|\n", 3.14159);
```

拆开读：总宽 8，其中小数占 2 位。输出 `    3.14|`（3.14 占 4 个字符，左边补 4 个空格）。

## 对齐的用处：做表格

```c
printf("%-10s%8s%8s\n", "科目", "分数", "等级");
printf("%-10s%8d%8c\n", "数学", 88, 'B');
printf("%-10s%8d%8s\n", "英语", 92, "A");
```

```
科目              分数      等级
数学                88        B
英语                92        A
```

字符串用 `%-10s` 左对齐（名字靠左更好读），数字用 `%8d` 右对齐（位数对齐才好比较大小）。

<TryIt title="自己调一下宽度，看表格怎么变">
{`#include <stdio.h>

int main(void)
{
    printf("%-10s%8s%8s\\n", "科目", "分数", "等级");
    printf("%-10s%8d%8c\\n", "数学", 88, 'B');
    printf("%-10s%8d%8c\\n", "英语", 92, 'A');
    return 0;
}
`}
</TryIt>

把 `%8d` 改成 `%3d`，看看表头会不会错位——错位的方向能帮你理解「最小宽度」的含义。

<Pitfall title="用空格手工对齐">
  ```c
  printf("数学      88\n");
  printf("英语英语  92\n");   /* 名字一变长就全乱了 */
  ```
  手工数空格在数据变化时必然错位。**宽度控制就是为了消灭手工空格**。
</Pitfall>

<Pitfall title="中文和英文的宽度不同">
  一个汉字在等宽字体里通常占 2 个字符位，而 `%-10s` 是按**字节/字符数**算的，
  所以中文对齐常会差一点。真要精确对齐中文表格，得自己按显示宽度补齐——
  现在只需知道「中英混排对齐会偏」这件事即可。
</Pitfall>

## 这一节的结论

`%宽度.精度说明符`：宽度管列宽（最小宽度、默认右对齐、`-` 改左对齐），
精度管小数位数（四舍五入）。有了它，输出才能变成一张能看的表。
