<KeyPoint>
  求最值这类问题的通用套路是：先把第一个元素当成答案，再从下一个开始逐个比较，发现更好的就更新。
  这样写不用猜「最大值大概有多大」，对全是负数的数据也照样成立——
  而如果初值随手写成 0，一批负数就会得到一个根本不在数据里的「最大值」。
</KeyPoint>

## 任务

> 读入 8 个整数（用空格分开）。输出四行：第一行是总和，第二行是最大值，
> 第三行是最小值，第四行是平均值（保留两位小数）。
> 数组长度用 `#define N 8` 写成常量。

输入 `12 7 25 3 19 8 14 30`，期望输出：

```
118
30
3
14.75
```

## 拆解

**第 1 步：把 8 个数读进数组**

读入本身就是一个标准的遍历循环——数组的长度已知，循环条件就是 `i < N`：

```c
for (i = 0; i < N; i++) {
    scanf("%d", &a[i]);
}
```

`scanf` 的第二个参数要写 `&a[i]`，也就是「第 i 个元素那个格子」的地址。这是 `scanf` 唯一比 `printf` 多写一个符号的地方，别漏。

**第 2 步：先假设第一个元素就是答案**

```c
max = a[0];
min = a[0];
```

这两行是这节课的核心。为什么不用 0 当最大值初值？因为数据里可能有负数：如果 8 个数是 `-5 -8 -3 -9 -1 -7 -2 -4`，最大值应该是 -1，但初值 0 比它们全都大，循环跑完 `max` 还是 0——一个根本不在数据里的数。

从数组自己的第一个元素出发就没有这个问题：它一定在数据里，后面每一个比它大的都能把它顶掉。最小值同理。

注意这两行必须写在**读入之后**：读之前 `a[0]` 还没有值。

**第 3 步：一遍循环同时做三件事**

求和、比大、比小可以在同一个循环里完成——它们都需要「访问每个元素」：

```c
sum = 0;
for (i = 0; i < N; i++) {
    sum = sum + a[i];
    if (a[i] > max) {
        max = a[i];
    }
    if (a[i] < min) {
        min = a[i];
    }
}
```

`sum` 在循环外清零，另外两个在循环外取了初值——三件事的准备工作都在循环外，循环体里只有「做」。

**第 4 步：平均值要写成浮点除法**

```c
printf("%.2f\n", (double)sum / N);
```

`sum` 和 `N` 都是整数，直接写 `sum / N` 会按整数除法算，小数部分被丢掉：118 / 8 得到的是 14，不是 14.75。所以要把其中一个操作数转成 `double`，让除法按浮点来做。

## 完整程序

```c
#include <stdio.h>

#define N 8

int main(void)
{
    int a[N];
    int i, sum, max, min;

    for (i = 0; i < N; i++) {
        scanf("%d", &a[i]);
    }

    sum = 0;
    max = a[0];
    min = a[0];

    for (i = 0; i < N; i++) {
        sum = sum + a[i];
        if (a[i] > max) {
            max = a[i];
        }
        if (a[i] < min) {
            min = a[i];
        }
    }

    printf("%d\n", sum);
    printf("%d\n", max);
    printf("%d\n", min);
    printf("%.2f\n", (double)sum / N);
    return 0;
}
```

对照期望输出检查一遍：8 个数的和是 118，最大 30，最小 3，平均 118 / 8 = 14.75。四个数字都对得上，程序才算写完。

## 再加一步：把矩阵转置

转置的意思是把行列互换：原来的第 i 行第 j 列，搬到结果的第 j 行第 i 列。用二维数组写出来只有一句核心代码：

```c
b[j][i] = a[i][j];
```

左边是新表的第 j 行第 i 列，右边是原表的第 i 行第 j 列——两个下标换了位置，这就是转置的全部。

**为什么必须用第二个数组**？因为转置是「成对」的操作：`a[0][1]` 和 `a[1][0]` 要互换。如果就地交换，等循环走到下一对时又会把它们换回去，结果等于什么都没做。所以规矩是：**读原数组、写另一个数组**，别在原地换。

<TryIt title="3 行 3 列的矩阵转置">
{`#include <stdio.h>

#define R 3
#define C 3

int main(void)
{
    int a[R][C] = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9},
    };
    int b[C][R];
    int i, j;

    for (i = 0; i < R; i++) {
        for (j = 0; j < C; j++) {
            b[j][i] = a[i][j];
        }
    }

    for (i = 0; i < C; i++) {
        for (j = 0; j < R; j++) {
            printf("%d", b[i][j]);
            if (j < R - 1) {
                printf(" ");
            }
        }
        printf("\\n");
    }
    return 0;
}
`}
</TryIt>

原来的三行是 `1 2 3`、`4 5 6`、`7 8 9`，转置之后输出的三行是 `1 4 7`、`2 5 8`、`3 6 9`——每一行的内容变成了原来每一列的内容。

注意 `b` 的定义写的是 `int b[C][R];`：原表是 R 行 C 列，转置之后就是 C 行 R 列，两个长度也换了位置。行列数不一样时这一点尤其要注意。

<Pitfall title="最大值初值随手写 0">
  数据全是负数时，最大值会变成 0——一个不在数据里的数。
  **判据**：只要初值不是来自数组本身，就要问一句「如果数据全是负数（或全是小数）会怎样」。
  正确写法是 `max = a[0];`（最小值同理），再让循环去更新它。
</Pitfall>

<Pitfall title="平均值用整数除法算">
  `double avg = sum / n;` 里的除法在赋值之前就已经按整数算完了，小数部分当场丢掉，
  再存进 `double` 也救不回来。
  **判据**：打印出来的平均值是个整数（比如 14 而不是 14.75），就是整数除法。把其中一个操作数写成 `(double)` 就行。
</Pitfall>

<Pitfall title="在原地交换做转置">
  写成「把 `a[i][j]` 和 `a[j][i]` 互换」，循环走完会发现矩阵变回了原样。
  **判据**：输出和输入完全一样，就是换了两遍。转置永远读原数组、写另一个数组。
</Pitfall>

## 这一节的结论
